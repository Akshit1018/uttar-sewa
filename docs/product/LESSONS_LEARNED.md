# Lessons learned

- Filenames and generic “autonomous PO” prompts can describe a different product. Trace `USER → UI → API → corpus` before writing code.
- A citation is only as honest as the row it cites. LLM-generated Q&A stored as “video evidence” is a grounded-looking hallucination.
- Japa is a local gesture. Network-first counters fail the core ritual.
- `/search` and `/ask` are different contracts. Chat must use refuse.
- Allowlist + `follow_redirects=True` is not an allowlist.
- Demo-open APIs need an explicit lock (`CONTROL_TOKEN`) that does not break tests when unset.
- Do not claim overlay/Watch or live YouTube ingest PRODUCTION_VALIDATED on a headless Linux agent.
